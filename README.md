# mustache

I've always had this problem. I stash some changes for later, and then I forget I have stashed changes. and obviously, I don't check my git status or extensions every single time.

I was thinking of a cool name and initially I thought "rememberstash" or "remember stash" but then I thought actually "mustache" is cool. So that's where the name comes from.

The idea is really simple: an extension that shows an indicator for when you have stashed changes. That's it.
